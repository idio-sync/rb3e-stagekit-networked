## Completion criteria

- `dashboard.py` is an entry point, with desktop composition and UI sections in a desktop package.
- Console song client/cache, album artwork, settings persistence, and Stage Kit transport have dedicated modules alongside the already extracted listener, video, song data, and integrations.
- Importing reusable services starts no UI, network connection, dependency installer, or worker.
- Song cache/HTTP failures preserve valid state and accurately report failure.
- Album artwork does not construct Tk images or invoke UI callbacks on worker threads; worker completion cannot touch a closed UI.
- Stage Kit transport owns its sockets, validates telemetry before display, and shuts down/restarts without duplicate receive loops.
- UI event delivery has an explicit queue, teardown cancels pending UI/scrobble work, and network callbacks do not directly mutate Tk state.
- Document remaining limitations and next-stage work honestly; completion is not a claim that every existing bug or future architecture issue is solved.
